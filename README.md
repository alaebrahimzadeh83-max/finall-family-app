# مهرینه خانواده V4 — Kotlin + XML

اپلیکیشن بومی مستقل برای خانواده. داشبورد، طراحی کارت‌محور، تماس با سالمند و جایگاه‌های وضعیت، درخواست کمک، یادآوری و آموزش.

**توجه:** این نسخه فرانت‌اند مستقل و قابل ساخت است، اما اتصال زنده دو گوشی هنوز پیاده‌سازی نشده است. تا وقتی Firebase/سرویس امن، احراز هویت و تأیید سالمند فعال نشود، پنل هیچ داده ساختگی را زنده نمایش نمی‌دهد. یک کد اتصال ساده بدون کنترل دسترسی، برای اطلاعات حساس سالمند امن نیست.

در مخزن جدا آپلود و GitHub Actions را اجرا کنید. بیلد در این محیط اجرا نشده است.


V5 update: redesigned family dashboard, location consent placeholder, five-question caregiver assistant. Live location and health synchronization are not implemented.
